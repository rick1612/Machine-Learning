# Career AI (CS Career Prediction)

Aplikasi prediksi minat karier mahasiswa Computer Science berbasis Machine Learning.

## App
[https://cs-career-predictor.streamlit.app/](https://cs-career-predictor.streamlit.app/)

## Model
- Algorithm: XGBoost
- Accuracy: 95.71%
- Classes: 6 Career Paths
- Training Data: 4,076 samples

## Tech Stack
- Python, Streamlit, XGBoost, Scikit-learn, TF-IDF

## How to Run
pip install -r requirements.txt
streamlit run app.py
